# Claude Cream

## Typography and emphasis

Claude Cream is a **warm editorial theme** for long coding sessions. It keeps
_supporting text quiet_, marks ~~obsolete behavior~~, and highlights
[project documentation](https://github.com/kakarrot-dev/claude-cream).

> Focus should be visible without turning every surface into a colored card.

- Default Light uses a warm ivory canvas.
- Default Dark uses warm charcoal.
- `Dark Dimmed` reduces nighttime glare without losing hierarchy.

Inline code such as `editor.lineHighlightBackground` must remain plain text,
not a badge or button.

```ts
const theme: Theme = await loadTheme('claude-cream')
```

| Mode | Purpose |
|---|---|
| Light | Daytime editing |
| Dark | Default dark workspace |
| High Contrast | Stronger focus and boundaries |

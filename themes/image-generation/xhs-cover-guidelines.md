# Claude Cream XHS 封面制作约束

用于小红书（XHS）新封面、封面改字与构图调整。默认交付包含准确文案与图像的实际封面；用户指定仅文案、无字底图、局部修改或原样复用时，按指定范围执行。

## 来源与适用边界

依据 XHS Studio 的 `skills/xiaohongshu-visuals/references/cover-design.md`、`brand/claude-cream-cover.json`（试排基线 `0.1.1`）及 2026-11-04 用户认可的两张概念封面整理：

| 本仓样例 | 可借鉴的效果 |
| --- | --- |
| [巨字终点](../../img/xhs/workflow-stop-block-v1.png) | “停”成为实体焦点，与手、画笔和跑道形成前后关系，文字本身参与表达停止条件 |
| [开跑对话](../../img/xhs/workflow-stop-dialogue-v1.png) | “先别跑”的对话、倾斜展示字和起跑动作呼应，先认出情境，再读到条件 |

两张原图从 XHS Studio 的 `skills/xiaohongshu-visuals/assets/cover-examples/` 按同名文件收录至本仓 `img/xhs/`。学习字形与空间关系时实际打开样图。认可的是图文共同表达的方向，不将纸人、跑道、画笔、“啥”的口吻或同一字效固定为后续模板。两图是 AI 生成概念图，用户认可不等于点击率已验证。

网站插画的无字底图、左侧约 38% 留白、微缩摄影及强调色面积限制只用于网站插画，不套用到 XHS 成品。XHS 的图像语言、构图和展示字根据本篇内容选择。

## 先确定本篇承诺

制作前读本轮标题、正文与可用材料，将以下要点合入现有文案或提示词；已有信息直接提取，影响承诺的事实缺口才需要补充：

```text
主题与目标读者：
读者的具体问题：
本篇可交付的所得及正文兑现位置：
封面准确文案（保留对象、动作、条件、数字与否定）：
一条值得画出来的动作、关系或变化：
继续阅读的理由与预期感受：
真实材料／概念演示及不可改动项：
画幅、浅色或深色、输出位置与版本：
```

- 标题与封面可分别交代精确信息和情境张力，兑现同一项承诺。
- 文案使用读者日常会说的任务词、问句或对话；口语化后仍保留原意与适用条件。
- 点击理由来自本篇真实的困境、期待、疑问或反差，不编造经历、威胁、资源和效果数字。

## 品牌色与字形

- 浅色沿用 [`style.json`](style.json) 的 `palette`：暖象牙与纸色作底、深炭黑作结构与文字、琥珀金形成主要强调；青绿仅按需要作少量状态点。
- 深色复用 [`../website/theme.css`](../website/theme.css) 的 `html[data-theme="dark"]` 中 `--color-canvas`、`--color-ink`、`--color-primary` 与 `--color-teal`，分别用于画布、主文字、琥珀强调与青绿状态色。按本篇选择模式，换构图或字形时保持品牌色。
- 真实截图、图表与证据保留原色和原貌，品牌色用于外围画布和新增文字。
- 正文与辅助阅读文字以 PingFang SC 为基线，代码使用 JetBrains Mono；展示字可按题意采用手绘、印刷、叠层或空间字形。
- 可控排字先核实字体安装与中文覆盖；模型绘制字形如实记录为生成展示字，不凭外观宣称某字体或真实字重。

## 图文共同构图

1. **一个主要文字焦点。** 用字级、字重、字宽和疏密形成主次，辅助文字退后；完整步骤、清单和解释交给正文图。
2. **一条具体图像关系。** 让图像表现本题的动作、处境、因果、选择或结果。概念题可用单一隐喻；作品和实测优先展示可回查的真实输出。
3. **共同安排阅读顺序。** 整体自上而下，同层自左向右；文字与主体共用留白、重心和动作方向。关键词可成为场景中的物件，也可沿视线或变化方向组织。
4. **字效服务含义。** 大小、倾势、材质、厚度和少量遮叠按表达选择，不叠满效果。核心笔画、人物表情、关键动作和证据保持可辨。
5. **按内容换表达。** 可用手绘、印刷拼贴、摄影或空间展示字；温和题材可以克制，比较题不默认两块信息卡，每篇不必都立体、倾斜或喊口号。
6. **删除无关层级。** 默认去掉页眉页脚、分类条、署名条和装饰线；必要对象词、来源、条件与演示身份仍需可见。图像若删去也不影响理解，应重新选择场景。

## 画幅与制作方式

- 默认以 `1080 × 1440`、`3:4` 为试排起点，沿用 XHS Studio 本地基线；用户指定画幅与复用原图比例优先。这是制作基线，不是平台强制规格。
- 留足文字与关键主体的边缘安全空间，实际检查裁切；不把网站横版文字安全区搬到竖版。
- **整体生成或编辑：**准确文案与场景共同输入，适合展示字、材质和遮叠关系；以最终图逐字核验，不能从提示词正确推断成图正确。
- **可控排字或合成：**精确字体、频繁改字、真实截图、图表、数字与标注使用原件及可控编辑；各图层仍服从同一构图。
- 错字、漏字、否定或条件丢失、关键遮挡必须修正，可局部编辑、重排或改用可控合成，并复查受影响区域。
- 真实界面和数据不由生成模型重绘成证据；概念场景与教学示例保持身份清楚。不添加未经要求的 Logo、水印、网址或随机字符。

## 成图验收与交付

实际打开每张最终整图及约 `360px` 宽的缩略图（本地复检尺寸），逐项核对：

- [ ] 对象和所得可被认出，标题与封面兑现同一承诺，正文有对应内容。
- [ ] 图文关系表达了具体的继续阅读理由，预期情绪有本题处境支撑，而不只是“醒目”。
- [ ] 文案、数字、标点、条件与否定逐项准确，口语化没有改变含义。
- [ ] 缩略图下主要文字焦点、阅读顺序和图像关系清楚，关键字形、动作与证据没有被遮挡或裁断。
- [ ] 品牌色、材料身份与本轮已确认的人物、数量、顺序和保持项均满足要求。
- [ ] 交付的是实际封面文件；保存准确文案、提示词或排字源、版本及看图结果，新版本另存，不覆盖已确认成品。

只有文案、提示词或无字底图不算默认封面完成。用户要求或存在实质选择时才制作多方案，变化落在文案角度、字形策略或空间关系上。若无法实际看图，明确标记视觉验收未完成；设计好评与发布后的点击效果分别记录。

# Claude Cream 壁纸生成提示词

你是一名数字壁纸设计师、编辑视觉导演和空间构图设计师。

请围绕我输入的主题，创作一张适合长期使用的 Claude Cream 风格壁纸。画面需要温暖、安静、耐看，在桌面图标、菜单栏、Dock、任务栏或移动端时间组件出现后，仍然保持清楚和克制。

【用户输入】

主题：{{填写主题，可留空}}

设备类型：{{Mac / Windows / Linux / iPhone / Android / 平板}}

输出尺寸：{{例如 2560 × 1664 / 3840 × 2160 / 3440 × 1440 / 1290 × 2796}}

画幅比例：{{16:10 / 16:9 / 21:9 / 9:19.5 / 4:3}}

模式：{{Light / Dark / 自动判断}}

图标区域：{{左侧 / 右侧 / 两侧 / 几乎没有图标}}

Dock 或任务栏位置：{{底部 / 左侧 / 右侧 / 隐藏}}

希望出现的主体：{{可留空，例如抽象结构、微缩装置、纸张、自然物体}}

需要避开的元素：{{可留空}}

【第一步：理解使用场景】

不要收到主题后立刻套用人物、装置、山景、星空或固定构图。

先判断：

壁纸会在哪种设备上显示；

屏幕的长宽比例；

菜单栏、时间、图标和 Dock 会占据哪些位置；

Light 或 Dark 模式下需要怎样的明度；

主题适合具象主体、抽象结构还是纯材质氛围；

长期观看时哪些细节会干扰窗口内容。

将主题压缩成一句清晰的视觉判断，再选择一种低干扰的表达。

每张壁纸只保留：

一个主要视觉中心；

一种主要空间关系；

一套稳定的明度层级；

一处克制的强调色；

一个清楚的图标安全区。

壁纸用于承托桌面内容，不要做成需要持续阅读的海报。

【第二步：选择画面类型】

画面可以选择：

一个小型微缩装置；

纸张、亚麻、灰泥和金属组成的静物；

自然形态与人工秩序之间的转换；

少量几何结构；

一段有方向感的路径或节点；

大面积材质背景中的一个细小主体；

光影、缺口、遮挡、断裂或平衡关系；

纯粹的暖色空间和层次变化。

人物不是默认选项。只有当人物姿态是主题中不可替代的一部分，并且不会干扰桌面内容时，才使用远距离背影或极简人物轮廓。

如果主题与 AI、系统、工作流或数字产品有关，可以使用模块、节点、纸张档案、轨道和轻微网格。

如果主题与思考、创作、安静或专注有关，可以使用纸张、墨迹、桌面物件、自然材料和大面积柔和光影。

如果没有输入主题，创作一张以暖象牙、深炭黑和琥珀金为核心的抽象编辑壁纸，不加入明确故事。

【视觉隐喻规则】

需要表达主题时，只使用一个核心隐喻。

可以通过以下关系表现：

完整与缺口；

自然与秩序；

聚合与分散；

连接与中断；

重量与平衡；

光线与遮挡；

柔软材料与坚硬结构；

小主体与大空间。

隐喻要在一眼看过去时成立，不依赖文字解释。

不要把主题名词直接变成图标，不要同时使用多个故事。

【画面风格】

Light 模式使用温暖的象牙白、奶油色、旧纸色和轻微灰泥质感，参考 `#f5f3e9`、`#f0eee4` 与 `#ffffff`。

Dark 模式使用暖炭灰、深褐黑和低亮度纸张色，参考 `#2d2e2d`、`#242524` 与 `#343533`。

主体可以使用哑光深炭黑金属、旧纸、天然亚麻、做旧黄铜、陶土和轻微磨砂表面。

琥珀金 `#b7791f` 或 `#e6bf7a` 只能用于一处路径、节点、边缘光或物体局部。

青绿色 `#2c6f75` 或 `#75b5bc` 最多作为一个微小状态点，也可以完全不用。

光线柔和，方向明确，阴影真实但对比度不高。整体带轻微模拟胶片颗粒，不做过度锐化。

画面要有编辑摄影、手工材料和安静工作空间的质感，避免商业广告和通用系统壁纸的塑料感。

【桌面构图】

根据图标区域自动调整主体位置。

图标位于左侧时，将主要主体放在中右区域，左侧保持低细节和稳定明度。

图标位于右侧时，将主要主体放在中左区域，右侧保持低细节和稳定明度。

两侧都有图标时，将主体缩小并放在中央偏下或中央偏上，左右两侧保持安静。

几乎没有图标时，可以采用偏置主体或更自由的负空间，但视觉中心仍不能压满画面。

底部有 Dock 或任务栏时，底部约 12% 至 18% 不放关键主体、强对比边缘或密集纹理。

顶部有菜单栏时，顶部约 5% 至 8% 保持均匀明度，不放高对比细线和复杂节点。

桌面壁纸可以使用：

主体偏置；

单一物体被大空间包围；

横向缓慢延伸的结构；

局部材质被柔和光线照亮；

对角线方向感；

中心区域轻微聚焦，边缘逐渐安静。

不要把主体放在屏幕正中央并占据大部分画面。窗口打开后，壁纸仍应作为背景退后。

【超宽屏构图】

21:9 或更宽比例要利用横向空间，不要把 16:9 画面简单拉伸。

主体可以位于左三分之一或右三分之一，另一侧保留连续、低细节的材质和光影。

横向路径只能有一条，不能贯穿整张图形成复杂信息流。

画面两端要保持完整，避免裁切后出现突兀的半个主体。

【移动端构图】

移动端壁纸要同时适配锁屏和主屏幕。

顶部约 22% 至 28% 为时间和状态信息安全区，保持低细节、低对比和稳定明度。

底部约 15% 不放关键主体，避免被快捷按钮、Dock 或手势区域遮挡。

主要视觉中心放在中下区域或中央偏侧，面向锁屏通知区域时仍保持呼吸空间。

不要把人脸、关键物体或高对比节点放在时钟、灵动岛、刘海和通知区域附近。

竖屏构图要重新组织空间，不要直接裁切横版壁纸。

【明度与可读性】

Light 模式要避免大面积纯白，图标和窗口边缘需要有足够区分度。

Dark 模式不要使用纯黑背景，保留暖炭灰层次，避免 OLED 屏幕上出现大块死黑。

图标安全区内保持明度稳定，避免细碎纹理、强烈光斑和明暗交界线。

整体对比度中低。唯一高对比区域应靠近主要视觉中心，并远离图标和系统组件。

不要使用大面积渐变。允许通过真实光影和材质变化形成柔和明度过渡。

【文字规则】

画面中不要生成：

标题；

标语；

日期；

时间；

Logo；

网址；

签名；

可读 UI；

随机字符；

水印。

桌面和锁屏上的文字由操作系统显示。

【色彩】

Light 模式以暖象牙和旧纸色为主，深炭黑提供结构，琥珀金用于唯一强调。

Dark 模式以暖炭灰和深褐黑为主，奶油色提供柔和亮部，浅琥珀金用于唯一强调。

强调色面积不超过画面的 3%。

青绿色如被使用，面积不超过画面的 0.5%。

不要使用冷蓝紫霓虹、彩虹渐变、大面积高饱和色或多色装饰。

【最终检查】

生成前检查：

尺寸和画幅比例是否准确；

构图是否符合设备类型；

图标、菜单栏、Dock、任务栏或时间区域是否有安全空间；

是否只有一个主要视觉中心；

是否只有一种主要空间关系；

主题表达是否克制；

桌面窗口打开后，壁纸是否会自然退到背景；

Light 或 Dark 模式的明度是否合适；

色彩和材质是否符合 Claude Cream；

是否没有文字、Logo、水印和随机字符；

是否还能删除任何多余元素。

【严格避免】

避免复杂叙事场景和多个视觉中心；

避免把封面海报构图直接用作壁纸；

避免主体巨大、居中并占满画面；

避免图标安全区出现密集纹理和强烈光斑；

避免将 16:9 画面拉伸为超宽屏；

避免将横版壁纸直接裁切为移动端；

避免山峰、星球、宇航员、城市夜景等通用壁纸模板；

避免机器人、芯片、电路板、全息屏和代码雨；

避免赛博朋克、蓝紫霓虹和发光网络；

避免玻璃拟态、塑料 3D 和高饱和渐变；

避免写实商业广告感；

避免图标堆叠和信息图；

避免过度锐化、HDR 和夸张景深；

避免文字、Logo、水印、签名、日期和网址。

最终生成一张：

准确适配目标设备、尺寸和系统组件；

为桌面图标和窗口保留低干扰安全区；

长期观看仍然安静、温暖、耐看；

保留 Claude Cream 的暖象牙、深炭黑、琥珀金和真实材质；

只有一个视觉中心和克制细节的高分辨率壁纸。

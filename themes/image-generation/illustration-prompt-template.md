# Claude Cream 插画生成提示词

你是一名编辑插画设计师、视觉隐喻导演和微缩场景艺术指导。

请围绕我输入的主题，创作一张有明确判断、单一隐喻和充足留白的 Claude Cream 编辑插画。画面用于网站封面或文章配图，标题和品牌文字由网页后期叠加，不在图像中生成。

【用户输入】

主题：{{填写主题}}

核心机制：{{填写希望表现的流程、关系或变化，可留空}}

画幅比例：{{16:9 / 5:2 / 1.91:1 / 4:5}}

用途：{{网站封面 / 文章配图 / 社交分享图}}

主体偏好：{{可留空，例如档案装置、桌面模型、机械结构、自然物体}}

需要避开的元素：{{可留空}}

【第一步：理解主题】

不要收到主题后直接套用机器人、齿轮、卡片、屏幕或固定构图。

先提炼主题中的：

核心观点；

核心机制；

主要矛盾；

因果关系；

最值得被看见的变化。

将主题压缩成一句清晰判断，再寻找一个能承载这句话的物理隐喻。

每张图只保留：

一个核心隐喻；

一个主要视觉中心；

一条可被看懂的关系或变化；

一处主要强调色。

不要把主题中的所有名词和功能逐一画出来。

【第二步：选择主体】

视觉主体可以是：

微缩机械装置；

纸张档案或卡片系统；

抽屉、轨道、刻度、节点和连接结构；

桌面工具或单一用途的物理界面；

自然物体与人工结构的组合；

人物局部与物体之间的关系；

空间中的缺口、遮挡、循环、错位或平衡。

人物不是默认主体。只有当人的动作、选择或关系是主题中不可替代的一部分时，才使用手部、背影或简化人物。

如果主题与流程、系统、协作、秩序、边界、效率或风险有关，优先使用装置、结构和空间关系。

如果主题与创作、记忆、成长、选择或人与工具的关系有关，可以使用纸张、手部、档案和带有使用痕迹的日常物件。

如果主题与 AI、互联网、算法或数字产品有关，画面需要带有轻微的技术联想，但仍表现为真实、可触摸的物理场景。

技术联想可以通过以下方式表现：

由少量琥珀金节点组成的路径；

纸张信息逐渐进入机械结构；

自然材料与规则网格之间的转换；

一个传统物体出现轻微模块化变化；

卡片、抽屉或轨道之间形成明确的数据流。

这些线索必须服务于核心隐喻，不能成为背景装饰。

不要直接堆放机器人、芯片、机械大脑、发光网络、数据大屏或通用科技图标。

【视觉隐喻规则】

视觉隐喻必须根据当前主题重新思考，不能机械复用过去的装置。

可以使用：

一个动作；

一个普通物品；

两个物体之间的关系；

材料从一种状态转为另一种状态；

结构的断裂、循环、错位、遮挡、平衡或失衡；

距离、方向、重量、大小和负空间；

自然形态与人工秩序之间的变化。

每张图只使用一个核心隐喻。

隐喻要能在没有解释文字时，引发与主题有关的联想。如果需要长篇说明才能看懂，应重新选择。

【避免直白和俗套】

不要把主题名词直接变成图标。

AI 主题不要默认使用机器人、芯片和电路板；

工作流主题不要默认使用齿轮和流水线；

知识主题不要默认使用书本和灯泡；

连接主题不要默认使用网络地球和握手；

成长主题不要默认使用树苗和阶梯；

安全主题不要默认使用盾牌和锁。

只有当这些元素经过重新组合、变形或形成新的关系，能够表达独特判断时，才可以使用。

【画面风格】

背景使用温暖的象牙白、旧纸色或轻微灰泥质感，参考 `#f5f3e9` 与 `#f0eee4`。

主体由哑光深炭黑金属、旧纸卡片、天然亚麻和少量做旧黄铜组成。

琥珀金 `#b7791f` 用于路径、节点或关键结构。青绿色 `#2c6f75` 只用于一个微小状态点，且可以完全不用。

采用编辑类微缩模型摄影质感。材质真实、细腻、有使用痕迹，但不追求超写实炫技。

光线为柔和的暖色自然侧光。阴影真实、边缘柔软，整体对比度中低，带轻微模拟胶片颗粒。

画面安静、克制、理性、有触感，像一本独立编辑杂志中的概念插图。

【构图】

根据用途和隐喻选择构图。

网站封面默认将主体放在画面中右区域，左侧约 38% 保持干净留白，用于网页叠加标题。

文章配图可以采用居中或偏置构图，但必须保留清晰的视觉中心和呼吸空间。

社交分享图要确保主体在缩略图中仍可辨认，重要结构不能贴近边缘。

可以使用：

单一装置偏置；

局部结构被放大；

两个物体彼此支撑、拉扯或远离；

线条从完整逐渐断裂；

材料从自然形态逐渐变为人工秩序；

大量负空间包围一个小主体；

主体沿画面对角线形成轻微方向感。

主体不必居中。不要平均分割画面，不要把所有元素做成同样大小。

网站封面底部约 20% 保持低细节和较暗明度，方便叠加浅色元信息。不要添加明显的黑色渐变蒙层。

【文字规则】

画面中不要生成：

标题；

副标题；

Logo；

网址；

日期；

可读 UI 文案；

随机字符；

水印或签名。

所有文字由网站或设计工具后期排版。

【色彩】

以暖象牙背景和深炭黑主体为主。

主要强调色只能使用琥珀金。

青绿色最多作为一个状态点或极短线段，面积不超过画面的 1%。

全部强调色面积合计不超过画面的 5%。

不要使用冷蓝紫霓虹、大面积鲜艳颜色、彩虹渐变或多色装饰。

【最终检查】

生成前检查：

是否只有一个核心隐喻；

是否只表达一条主要关系或变化；

主体选择是否来自当前主题；

技术意象是否克制并服从物理场景；

是否避开了常见图标和模板化装置；

留白和文字安全区是否适合所选用途；

材质、光线和色彩是否符合 Claude Cream；

是否没有生成任何文字、Logo 或随机字符；

是否还能删除多余元素。

【严格避免】

避免所有主题都套用同一种卡片机器、抽屉、齿轮或传送带；

避免为了技术感加入电路板、机器人、芯片、全息屏和数据大屏；

避免复杂叙事场景和多组主体；

避免写实商业广告感；

避免 3D 塑料模型和光滑玩具质感；

避免扁平企业矢量插画；

避免商业科技宣传页；

避免信息图和功能介绍图；

避免图标堆叠；

避免多个隐喻同时出现；

避免多种强调色；

避免满版构图和过度锐化；

避免可读文字、乱码、Logo、水印、签名、日期和网址。

最终生成一张：

以准确理解主题为起点；

用一个可触摸的物理隐喻表达核心机制；

保留暖象牙、深炭黑、琥珀金和真实材质；

具有充足留白、单一视觉中心和编辑摄影质感；

适合后期叠加网页标题的 Claude Cream 编辑插画。

# Claude Cream 个人社交头像生成提示词

你是一名编辑肖像摄影师、人物视觉导演和个人品牌设计师。

请根据我提供的人物信息和参考照片，创作一张适合个人社交账号使用的 Claude Cream 风格头像。头像需要在小尺寸和圆形裁切下依然清楚、自然、有辨识度。

【用户输入】

参考照片：{{上传 1 至 3 张清晰照片，至少包含一张正脸}}

人物气质：{{例如冷静、友好、理性、创作者、技术感}}

职业或身份：{{可留空，例如 AI 产品经理、独立开发者、设计师}}

希望保留的特征：{{例如发型、眼镜、胡须、痣、脸型}}

服装偏好：{{可留空，例如深炭色圆领、米色衬衫、简洁夹克}}

背景偏好：{{暖象牙纯色 / 轻微纸张质感 / 简化编辑空间}}

头像比例：1:1

【第一步：理解人物】

不要收到职业名称后直接套用西装、电脑、耳机或科技背景。

先从参考照片和人物信息中提炼：

最稳定的面部特征；

最自然的神态；

希望传达的性格；

适合社交头像的识别重点；

需要避免的刻板职业符号。

将人物印象压缩成一句清晰判断，再决定姿态、表情、服装和背景。

头像只保留：

一个人物；

一个明确表情；

一种主要光线；

一个简单背景；

最多一个很小的个人识别细节。

【第二步：保持人物相似度】

参考照片存在时，优先保持真实身份特征：

脸型与头部比例；

眼睛、眉毛、鼻子和嘴部关系；

发际线、发型和发色；

眼镜、胡须、痣等稳定特征；

真实年龄段和自然肤色。

不要自动美化成模板化网红脸，不要改变种族特征，不要明显改变年龄、体型或性别表达。

皮肤可以干净，但要保留自然纹理。不要磨皮过度，不要把五官做得完全对称。

如果参考照片之间存在差异，以正脸、清晰、光线自然的照片为主要依据。

【第三步：选择肖像形式】

默认使用肩部以上近景肖像，人物略微偏离正中心，眼睛接近画面上方三分之一。

可以选择：

正面看向镜头，适合直接、可信的个人形象；

轻微三分之四侧脸，适合安静、思考型气质；

自然微笑，适合友好、开放的社交形象；

平静中性表情，适合理性、专业的个人品牌；

轻微低头或转头，只有在不影响小尺寸识别时使用。

不要使用夸张侧脸、遮住半张脸、低头看设备或远距离全身构图。

【视觉风格】

背景使用温暖的象牙白、奶油色或轻微旧纸色，参考 `#f5f3e9` 与 `#f0eee4`。

服装以深炭黑 `#29271d`、暖灰、米色或低饱和棕色为主。款式简洁，没有可读品牌标志。

允许使用极少量琥珀金 `#b7791f` 作为眼镜细节、衣领缝线、背景小色块或轮廓边缘。

光线为柔和的暖色自然侧光，面部阴影真实、过渡柔和，眼神有清晰高光。

整体质感介于编辑肖像摄影和轻微手工插画之间。保留真实面部结构，同时带一点纸张颗粒、柔和边缘和克制的艺术处理。

不要生成商业证件照，也不要做成夸张卡通、二次元或塑料感 3D 头像。

【构图与裁切】

输出比例固定为 1:1。

人物头部和肩部完整，头顶保留约 8% 至 12% 安全空间。

脸部占画面高度约 45% 至 58%，确保缩小后仍可识别。

眼睛、鼻子和嘴部必须位于中心安全区，适配圆形头像裁切。

背景保持简洁，人物轮廓与背景之间有清楚但柔和的明度差。

不要让头顶、下巴、眼镜或发型被裁切。不要把脸贴近画面边缘。

【背景规则】

背景只能选择一种表达：

暖象牙纯色；

轻微纸张或灰泥纹理；

极简的编辑空间轮廓；

一个低对比的几何色块。

如果需要体现 AI、产品或技术身份，只能加入一处很轻的结构线、节点或模块化纸张暗示。

这些元素必须低对比、不可读，并且不能分散对人物面部的注意力。

不要使用代码雨、芯片、电路板、机器人、数据大屏、发光网络、办公桌全景或大量科技图标。

【表情与气质】

表情要自然，不做夸张大笑、紧绷商务微笑或故作深沉。

眼神清楚、有交流感，嘴角和眉眼保持人物原有特征。

专业感来自姿态、光线和克制构图，不依赖西装、领带、双臂交叉或豪华办公室。

创作者气质来自真实、放松和个人细节，不依赖画笔、相机、键盘等道具堆叠。

【文字与标志】

画面中不要出现：

文字；

姓名首字母；

Logo；

网址；

水印；

签名；

可读 UI；

无关品牌标志。

【最终检查】

生成前检查：

人物是否与参考照片保持相似；

年龄、肤色、脸型和五官关系是否自然；

是否只有一个人物；

小尺寸下脸部是否仍清楚；

圆形裁切是否不会切掉关键特征；

表情是否符合输入的气质；

背景是否足够简单；

技术暗示是否克制；

色彩是否符合 Claude Cream；

是否没有文字、Logo、水印和随机字符；

是否还能删除任何多余道具。

【严格避免】

避免模板化网红脸和过度美化；

避免改变种族、年龄、性别表达和稳定面部特征；

避免蜡像皮肤、塑料质感和过度磨皮；

避免夸张锐化、HDR 和高饱和肤色；

避免强烈蓝紫霓虹和赛博朋克背景；

避免职业图标、科技图标和道具堆叠；

避免复杂办公室、城市夜景和全景环境；

避免多人、宠物或无关角色；

避免夸张卡通、二次元和 3D 玩偶风；

避免证件照式僵硬正面打光；

避免头顶、下巴、眼镜和发型被裁切；

避免文字、Logo、水印、签名、日期和网址。

最终生成一张：

保持人物真实身份特征；

在小尺寸和圆形裁切下清楚可辨；

背景温暖、简洁、克制；

带有柔和编辑肖像质感；

适合长期作为个人社交账号头像的 Claude Cream 风格正方形肖像。
